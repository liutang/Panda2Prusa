🐼 Panda2Prusa

Convert Bambu Studio / OrcaSlicer .3mf projects to PrusaSlicer, or remap the tool heads of a PrusaSlicer .3mf.

Project

Plates

Leave all selected to convert every plate.

Filament → tool head mapping

Drag each filament onto the tool head it should print from (or focus it and use the arrow keys). Unused tool heads are spacers, so a 3-color model can go on tools 1, 5 and 8.

This is a PrusaSlicer project, so each filament's preset, color and temperatures move to its new tool head; a filament already on that tool head takes the vacated one.

    PrusaSlicer only shows multiple colors under a printer profile with multiple extruders/tools (MMU3, XL 2T/5T…).
